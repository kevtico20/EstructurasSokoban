# Estructuras Sokoban

Estructuras Sokoban is a Java-based implementation of the classic Sokoban game. This project was collaboratively developed by three contributors.

## Project Overview

Sokoban is a puzzle game where the player pushes boxes around in a warehouse, trying to get them to designated storage locations. The goal is to push all boxes to the target locations with the least number of moves.

## Features

- Classic Sokoban gameplay
- Multiple levels with increasing difficulty
- Intuitive user interface
- Responsive design with CSS

## Technologies Used

- **Java**: The main programming language used for the game's logic and functionality.
- **CSS**: Used for styling the user interface.

# Sokoban Game

A classic Sokoban puzzle game implementation in Java.

## Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher installed
- Basic knowledge of terminal/command prompt usage

### Installation

1. Navigate to the project directory:
```sh
cd EstructurasSokoban
```

2. Compile the Java files:
```sh
javac -d bin src/*.java
```

3. Run the game:
```sh
java -cp bin Main
```

## Usage

- Use the arrow keys to navigate and push the boxes
- The goal is to move all the boxes to the designated spots
- Press 'R' to restart the current level
- Press 'Q' to quit the game
